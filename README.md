# College Canteen Management & Digital Ordering

React + FastAPI application for student ordering, simulated UPI payments, digital tokens, and canteen administration.

## Team layout

- `backend/` contains the FastAPI API, business rules, database access, migrations, and tests.
- `frontend/` contains the React interface.
- Each layer is organized by responsibility to reduce overlap between teammates.

## Planned workflow

1. Foundation and configuration
2. Models, migrations, repositories, and seed data
3. Core APIs
4. Payments and tokens
5. Student experience
6. Admin experience
7. Tests and end-to-end verification
